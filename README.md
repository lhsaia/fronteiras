# 🌍 Mural Fronteiras Invisíveis do Futebol

Um mapa interativo para explorar os episódios do podcast **Fronteiras Invisíveis do Futebol**, criado por **Filipe Figueiredo** e **Matias Pinto** (Central 3).

Este projeto organiza os episódios geograficamente, permitindo que os ouvintes naveguem pela história do futebol e da política mundial através de um mapa dinâmico.

## 🚀 Funcionalidades

- **Mapa Interativo:** Navegue pelo globo e encontre episódios baseados na localização geográfica tratada.
- **Agrupamento de Episódios:** Episódios que tratam da mesma região ou são divididos em partes (Pt.1, Pt.2) são agrupados em um único pino, com um seletor para alternar entre eles.
- **Player Integrado:** Ouça o podcast diretamente no navegador enquanto explora o mapa.
- **Design Responsivo:** Interface otimizada para desktop e dispositivos móveis.
- **Estética Dark/Premium:** Visual moderno com filtros de mapa customizados e efeito de vidro (glassmorphism).

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3:** Estrutura e estilização moderna com variáveis CSS.
- **JavaScript (Vanilla):** Lógica de manipulação de dados e interface.
- **[Leaflet.js](https://leafletjs.com/):** Biblioteca open-source para mapas interativos.
- **JSON:** Armazenamento de dados dos episódios (títulos, links, coordenadas, imagens).

## 📂 Estrutura do Projeto

- `index.html`: Estrutura principal da página.
- `style.css`: Estilização e temas.
- `app.js`: Lógica do mapa, agrupamento de coordenadas e player.
- `episodes.json`: Base de dados contendo as informações de todos os episódios.
